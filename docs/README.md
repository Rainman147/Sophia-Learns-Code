## Current build program

**Experience Loop 0** is coordinated by GitHub issue #11.

The required build order is:

```text
E0 scripted First Contact experience
  → E1 real browser Python
  → E2 prediction and execution trace
  → E3 deterministic feedback and recovery
  → E4 learner snapshot, mastery, and rewards
  → E5 second mission proves reuse
  → E6 complete first five-mission case
```

Broad curriculum implementation waits until this loop is validated with immediate, delayed, and transfer evidence.
